SAINSMAMBA PATCH v2.1.3 — IMPORT PESERTA DARI EXCEL
====================================================

FITUR BARU
- Menu Peserta Super Admin: tombol Import Excel.
- Menu Peserta Guru: tombol Import Excel.
- Download template Excel langsung dari modal import.
- Preview data sebelum import.
- Password default opsional untuk peserta baru.
- Username yang sudah ada (role student) diperbarui / upsert.
- Username milik Guru / Super Admin tidak akan ditimpa.
- Validasi baris dan laporan error.
- Backend Apps Script batch write agar import banyak peserta lebih ringan.
- Maksimal 5.000 peserta per proses import.

KOLOM TEMPLATE
- nama_lengkap (wajib)
- username (wajib; NIS/NISN juga dapat dipakai sebagai header)
- kelas (wajib)
- password (wajib untuk peserta baru jika Password Default tidak diisi)
- email (opsional)
- no_hp (opsional)
- status (ACTIVE / INACTIVE; default ACTIVE)

LANGKAH FRONTEND
1. Copy folder/file patch ke root repository GitHub SainsMasemba.
2. Replace file bila diminta.
3. Commit + push ke branch main.
4. Vercel akan redeploy otomatis.

LANGKAH APPS SCRIPT (WAJIB)
1. Buka project Google Apps Script SainsMasemba.
2. Replace isi Admin.gs dengan file patch apps-script/Admin.gs.
3. Replace isi Code.gs dengan file patch apps-script/Code.gs.
4. Save.
5. Deploy > Manage deployments.
6. Klik Edit (ikon pensil) pada Web App aktif.
7. Version: pilih New version.
8. Deploy.
9. URL /exec biasanya tetap sama, jadi Environment Variable Vercel tidak perlu diubah.

CARA IMPORT
1. Login sebagai Super Admin atau Guru.
2. Menu Peserta > Import Excel.
3. Download template.
4. Isi peserta di sheet "Peserta".
5. Upload file .xlsx / .xls.
6. Periksa preview.
7. Bila banyak akun baru tidak memiliki password di Excel, isi Password Default.
8. Klik Import Peserta.
9. Periksa ringkasan Dibuat / Diperbarui / Dilewati / Error.

PERILAKU UPDATE
- Username baru -> membuat peserta baru.
- Username peserta sudah ada -> update nama, kelas, email, no HP, status.
- Password peserta lama hanya berubah bila kolom password Excel diisi.
- Username yang sudah dipakai akun Guru/Super Admin -> error, tidak ditimpa.
- Username duplikat dalam file Excel -> baris kedua dan seterusnya dilewati.

CATATAN
Tidak ada perubahan pada ID Spreadsheet, Folder Drive, atau Environment Variable Vercel.
